Document Intake Agent

Agente demonstrativo para triagem de documentos com schema fechado, validações determinísticas, confidence threshold, abstention e revisão humana.

Cenário

Uma operação recebe documentos, precisa identificar o tipo, extrair campos, validar consistência e decidir para qual fila encaminhar cada caso.

Exemplo de saída

{
  "document_type": "proof_of_address",
  "confidence": 0.94,
  "fields": {
    "name": "EXAMPLE PERSON",
    "issue_date": "2026-08-01"
  },
  "validation": {
    "required_fields_present": true,
    "date_within_policy": true
  },
  "route": "auto_approved"
}

O diferencial

Schema fechado

A IA responde dentro de uma estrutura validável.

Abstention

O sistema sabe quando não há evidência suficiente.

Human-in-the-loop

Exceções seguem para revisão, não para decisão automática forçada.

Evals

Dataset de avaliação acompanha qualidade e regressões.

Enquadramento

Este é um laboratório demonstrativo. O objetivo é mostrar desenho de agente confiável, não alegar implantação em cliente.
