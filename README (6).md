# Nharryme Workspace

> Projeto pessoal real · conteúdo privado omitido

## Visão

Workspace web pessoal desenvolvido para centralizar a experiência digital da Nharryme em uma interface própria, em vez de espalhar rotinas e referências entre ferramentas desconectadas.

Este case é publicado de forma propositalmente limitada: o produto é real, mas conteúdo, dados pessoais e detalhes específicos de uso não fazem parte do portfólio público.

## O que vale mostrar no portfólio

- descoberta de necessidade e organização do produto;
- desenho de uma experiência de workspace pessoal;
- arquitetura de informação e navegação;
- interface web responsiva;
- decisões de UX para reduzir fricção;
- evolução iterativa a partir do uso real.

## Princípio de produto

```text
necessidade pessoal
      ↓
fluxo simples
      ↓
interface própria
      ↓
menos contexto espalhado
      ↓
workspace útil no dia a dia
```

## Privacidade

Screenshots públicos devem usar conteúdo fictício, desfocado ou previamente autorizado. O case não deve expor dados pessoais, credenciais, mensagens ou informações sensíveis.
